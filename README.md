# Homebound — Home Screen Prototype

A new iPhone-first PWA built from scratch to match the approved Homebound Home sketch.

## Files
- `index.html`
- `styles.css`
- `app.js`
- `manifest.webmanifest`
- `service-worker.js`
- `assets/` app icons

## GitHub Pages
Upload all files to the repository root, then enable GitHub Pages from the main branch.

This prototype intentionally implements Home only. The other six tabs explain that they are awaiting Home approval.
