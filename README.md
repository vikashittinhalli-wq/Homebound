# Homebound — Home + Journey v2 fix

This build fixes the Journey sheet on iPhone and restores the original Freedom Countdown financial figures.

## Fixes
- Tall dialogs now remain inside the screen and scroll independently.
- A sticky **Done** button remains visible at the top of every dialog.
- Existing `freedomCountdownData` is automatically imported.
- Placeholder Journey balances are replaced with the original tracked balances and rates.
- Neutral milestone names remain on the map; the real account name appears after tapping.
- Debt totals exclude the Freedom Fund so the overall debt calculation is not distorted.
- Payments now estimate interest based on elapsed days.
